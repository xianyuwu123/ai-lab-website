本文整理自福州大学《微机原理与接口技术》吴衔誉教授第八章课件，系统讲解 STM32 通用定时器概述、普通定时器的结构、工作模式、相关寄存器、固件库函数以及脉冲宽度调制与定时器实例六大板块。

一、STM32 通用定时器概述

定时器是单片机里最常用、也最容易让人「看不懂寄存器」的外设。它的本质其实很简单：一个计数器，在时钟驱动下不停加或减，加到某个值就「溢出」一次，溢出时产生中断、触发 DMA（Direct Memory Access，直接存储器访问），或者翻转一个输出引脚。把这套机制玩明白，就能做延时、测脉宽、发 PWM（Pulse Width Modulation，脉冲宽度调制）驱动电机和舵机、接编码器读转速，甚至让多个定时器协同工作。

STM32（本文以 STM32F1 系列为例）一共提供了 11 个定时器，分为高级、普通、基本三大类，再加上 2 个看门狗和 1 个系统嘀嗒定时器（SysTick）。本章围绕普通定时器（TIM2~TIM5）展开，因为它结构最典型、用途最广，高级定时器和基本定时器都是在它的基础上做加减法。

1.1 定时器的总体分类

STM32 一共有 11 个定时器，包括 2 个高级控制定时器、4 个普通定时器和 2 个基本定时器，另外还有 2 个看门狗定时器和 1 个系统嘀嗒定时器（SysTick）。

通用定时器由一个通过可编程预分频器驱动的 16 位自动装载计数器构成。它适用于多种场合，包括测量输入信号的脉冲长度（输入捕获），或者产生输出波形（输出比较和 PWM）。使用定时器预分频器和 RCC（Reset and Clock Control，复位和时钟控制）预分频器，脉冲长度和波形周期可以在微秒到几毫秒之间调整。每个定时器都是完全独立的，不互相共享任何资源，但它们可以一起同步操作。

1.2 高级控制定时器（TIM1 和 TIM8）

高级控制定时器（TIM1 和 TIM8）各由一个 16 位的自动装载计数器组成，由一个可编程的预分频器驱动。它们适合多种用途，包含测量输入信号的脉冲宽度（输入捕获），或者产生输出波形（输出比较、PWM、嵌入死区时间的互补 PWM 等）。

TIM1 和 TIM8 与其他通用定时器是完全独立的，不共享资源，但可以同步操作。它们能够产生 3 对 PWM 互补输出，常用于三相电机的驱动，时钟由 APB2 的输出产生，最高频率 72 MHz。

TIM1 和 TIM8 的主要特性：

  1. 16 位向上、向下、向上 / 向下自动装载计数器；
  2. 16 位可编程（可实时修改）预分频器，分频系数为 1~65536 的任意数值；
  3. 多达 4 个独立通道，可用于输入捕获、输出比较、PWM 生成和单脉冲模式输出；
  4. 死区时间可编程的互补输出（普通定时器不具备）；
  5. 使用外部信号控制定时器和定时器互连的同步电路；
  6. 允许在指定数目的计数器周期之后更新定时器寄存器的重复计数器（普通定时器不具备）；
  7. 刹车（Break）输入信号可以将定时器输出信号置于复位状态或者一个已知状态；
  8. 下列事件发生时产生中断 / DMA：更新（计数器溢出或初始化）、触发事件（启动 / 停止 / 初始化 / 内部外部触发计数）、输入捕获、输出比较、刹车信号输入；
  9. 支持针对定位的增量（正交）编码器和霍尔传感器电路；
  10. 触发输入可作为外部时钟或者按周期的电流管理。

1.3 普通定时器（TIM2~TIM5）

普通定时器（TIM2~TIM5）各由一个通过可编程预分频器驱动的 16 位自动装载计数器构成。它们适用于多种场合，包括测量输入信号的脉冲长度（输入捕获），或者产生输出波形（输出比较和 PWM）。每个定时器完全独立，没有互相共享任何资源，但可以一起同步操作。

普通定时器的主要特性：

  1. 16 位向上、向下、向上 / 向下自动装载计数器；
  2. 16 位可编程（可实时修改）预分频器，分频系数为 1~65536 的任意数值；
  3. 4 个独立通道，可用于输入捕获、输出比较、PWM 生成（边沿或中央对齐模式）和单脉冲模式输出；
  4. 使用外部信号控制定时器和定时器互连的同步电路；
  5. 下列事件发生时产生中断 / DMA：更新、触发事件、输入捕获、输出比较；
  6. 支持针对定位的增量（正交）编码器和霍尔传感器电路；
  7. 触发输入可作为外部时钟或者按周期的电流管理。

1.4 基本定时器（TIM6 和 TIM7）

基本定时器（TIM6 和 TIM7）各由一个通过可编程预分频器驱动的 16 位自动装载计数器构成。它们可作为通用定时器提供时间基准，特别地，可为数模转换器（DAC，Digital-to-Analog Converter）提供时钟。实际上，它们在芯片内部直接连接到 DAC 并通过触发输出直接驱动 DAC。这两个定时器相互独立，不共享任何资源。

1.5 定时器的时钟

定时器的时钟由系统时钟提供，但使用定时器时钟时应注意选择正确的总线。关键点是：定时器的时钟不是直接来自 APB1 或 APB2，而是来自输入为 APB1 或 APB2 的一个倍频器（更准确地说，APB 预分频器之后接了一个定时器时钟倍频器）。

以普通定时器 TIM2 为例：

  • 当 APB1 的预分频系数为 1 时，倍频器不起作用，定时器时钟频率等于 APB1 的频率；
  • 当 APB1 的预分频系数为其他数值时，倍频器起作用，定时器时钟频率等于 APB1 频率的两倍。

这样设计的原因在于：APB1 不但要为 TIM2~TIM7 提供时钟，还要为其他外设提供时钟；设置倍频器可以在保证其他外设使用较低时钟频率时，TIM2~TIM7 仍能得到较高的时钟频率。

在 STM32F1 的典型配置下，系统时钟 72 MHz 时，APB2 上挂的 TIM1/TIM8 时钟为 72 MHz；APB1 上挂的 TIM2~TIM7 时钟也为 72 MHz（APB1 预分频不为 1，经 2 倍频得到）。

记忆点：11 个定时器按能力从强到弱是「高级 → 普通 → 基本」。高级定时器多了互补输出、死区、重复计数器和刹车；基本定时器只能做时基、驱动 DAC；普通定时器功能最均衡，是本章主角。时钟来自 APB 倍频器，这一点直接决定了后面定时时间怎么算。

二、普通定时器的结构

STM32 内置 4 个可同步运行的普通定时器（TIM2~TIM5）。每个定时器都有 1 个 16 位自动加载的递加 / 递减计数器、1 个 16 位预分频器和 4 个独立通道。每个通道都可用于输入捕获、输出比较、PWM 和单脉冲模式输出。任一标准定时器都能用于产生 PWM 输出。每个定时器都有独立的 DMA 请求机制。通过定时器链接功能，它还能与高级控制定时器共同工作，提供同步或事件链接功能。

2.1 时基单元

时基单元包含 3 个核心寄存器：计数器寄存器（TIMx_CNT）、预分频寄存器（TIMx_PSC）和自动装载寄存器（TIMx_ARR）。

可编程通用定时器的主要部分是一个 16 位计数器和与其相关的自动装载寄存器。这个计数器可以向上计数、向下计数或者向上向下双向计数。此计数器时钟由预分频器分频得到。计数器、自动装载寄存器和预分频器寄存器可以由软件读写，在计数器运行时仍可以读写。

计数器由预分频器的时钟输出 CK_CNT 驱动，仅当设置了计数器 TIMx_CR1 寄存器中的计数器使能位（CEN）时，CK_CNT 才有效。真正的计数器使能信号 CNT_EN 是在 CEN 被置 1 后的一个时钟周期后才被设置。

影子寄存器与预装载机制

这是初学者最容易迷糊的地方。部分寄存器（如 TIMx_PSC、TIMx_ARR 和捕获 / 比较寄存器 TIMx_CCRy）在物理上对应两个寄存器：

  • 一个是可进行读写的寄存器，称为预装载寄存器；
  • 另一个看不见、无法直接读写、但真正起作用的寄存器，称为影子寄存器。

用户写值的过程是：用户值 → 预装载寄存器 → 影子寄存器 → 真正起作用。如果不使用影子寄存器，用户值写到预装载寄存器后立刻起作用。

影子寄存器的存在起到缓冲作用：它可以在发生更新事件（UEV）时，被统一更新为预装载寄存器的内容，从而让所有真正需要起作用的寄存器在同一个时间进行更新，避免中途改参数造成波形错乱。

  • 自动装载寄存器（TIMx_ARR）是预先装载的，写或读 ARR 将访问预装载寄存器；
  • 根据 TIMx_CR1 中自动装载预装载使能位（ARPE，位 7）的设置，预装载寄存器的内容被立即（ARPE=0）或在每次更新事件 UEV 时（ARPE=1）传送到影子寄存器；
  • 当计数器达到溢出条件且 UDIS 位等于 0 时，产生更新事件；更新事件也可由软件产生；
  • 预分频器将时钟频率按 1~65536 的任意值分频，它基于一个 16 位寄存器（TIMx_PSC）控制的 16 位计数器，带有缓冲器，能在工作时被改变；新的预分频器参数在下一次更新事件到来时被采用（通过影子寄存器）。

2.2 计数器模式

TIM2~TIM5 可向上计数、向下计数、向上 / 向下双向计数（中央对齐模式）。

（1）向上计数模式

计数器从 0 计数到自动加载值（TIMx_ARR 的内容），然后再从 0 开始计数并产生一个计数器溢出事件。每个计数器溢出时可以产生更新事件；在 TIMx_EGR 寄存器中（通过软件或主模式控制器）设置 UG 位同样可以产生更新事件。设置 TIMx_CR1 中的 UDIS 位可以禁止更新事件，避免在向预装载寄存器写入新值时更新影子寄存器。

如果设置了 TIMx_CR1 中的 URS 位（更新请求选择），设置 UG 位将产生一个更新事件 UEV，但硬件不设置 UIF 标志（即不产生中断及 DMA 请求），这能避免在捕获模式下清除计数器时同时产生更新和捕获中断。

当发生一个更新事件时，所有寄存器都被更新，硬件同时（依据 URS 位）设置更新标志位（TIMx_SR 中的 UIF 位），并执行：预分频器缓冲区被置入 TIMx_PSC 的值；自动装载影子寄存器被重新置入 TIMx_ARR 的值。

（2）向下计数模式

计数器从自动装入的值（TIMx_ARR）开始向下计数到 0，然后从自动装入的值重新开始计数，并产生一个计数器溢出事件。

（3）中央对齐模式（向上 / 向下计数）

计数器从 0 开始计数到自动加载值减 1（TIMx_ARR−1），产生一个计数溢出事件，然后向下计数到 1 并产生一个计数器下溢事件，再从 0 开始重新计数。在这个模式中，不能写入 TIMx_CR1 中的 DIR 方向位，它由硬件更新并指示当前计数方向。

使用中央对齐模式需要注意：

  1. 进入中央对齐模式时使用当前的向上 / 向下计数配置，软件不能同时修改 DIR 和 CMS 位；
  2. 不推荐在运行中央对齐模式时改写计数器，这会产生不可预知的结果；特别地，若写入计数器的值大于自动重装载值（TIMx_CNT > TIMx_ARR），方向不会被更新；
  3. 最保险的方法是在启动计数器之前产生一个软件更新（设置 TIMx_EGR 的 UG 位），不要在计数过程中修改计数器的值。

2.3 时钟选择

定时器的计数脉冲可由 4 种时钟源提供：

  1. 内部时钟（CK_INT）；
  2. 外部时钟模式 1；
  3. 外部时钟模式 2；
  4. 内部触发输入。

（1）内部时钟源（CK_INT）

当 TIMx_SMCR 的 SMS=000 时，CEN、DIR（TIMx_CR1）和 UG（TIMx_EGR）是事实上的控制位，只能被软件修改（UG 位仍被自动清除）。只要 CEN 位被写成 1，预分频器的时钟就由内部时钟 CK_INT 提供。

（2）外部时钟模式 1

当 TIMx_SMCR 的 SMS=111 时，外部时钟模式 1 被选中，计数器可以在选定输入端的每个上升沿或下降沿计数。

配置向上计数器在 TI2 输入端上升沿计数的步骤：

  1. 配置 TIMx_CCMR1 寄存器 CC2S=01，使通道 2 检测 TI2 输入的上升沿；
  2. 配置 TIMx_CCMR1 的 IC2F[3:0] 选择输入滤波器带宽（不需要滤波器则保持 IC2F=0000）；
  3. 配置 TIMx_CCER 寄存器 CC2P=0，选定上升沿极性；
  4. 配置 TIMx_SMCR 的 SMS=111，选择外部时钟模式 1；
  5. 配置 TIMx_SMCR 的 TS=110，选定 TI2 作为触发源；
  6. 设置 TIMx_CR1 的 CEN=1，启动计数器。

（3）外部时钟模式 2

令 TIMx_SMCR 中的 ECE=1 即可选中此模式。计数器能够在外部触发 ETR 的每一个上升沿或下降沿计数。

STM32 在很多功能中都提供了数字滤波器，简单说就是多次检视为一次有效，达到滤波效果：滤波器由一个事件计数器组成，假设检测高电平、滤波 N 次，记录 N 个事件后计数器产生一个输出跳变，即连续 N 次采样都是高电平时才确认是有效电平，由此过滤掉干扰信号。外部触发滤波器 ETF 的定义可查阅芯片手册；值得关注的是采样频率的选择，以设置值 0000 为例，其采样频率为 fDTS，而 fDTS 的取值与 CKD 位有关。

配置在 ETR 下每 2 个上升沿计数一次的向上计数器示例：

  1. 不需要滤波器，置 TIMx_SMCR 的 ETF[3:0]=0000；
  2. 设置预分频器，置 TIMx_SMCR 的 ETPS[1:0]=01；
  3. 设置在 ETR 的上升沿检测，置 TIMx_SMCR 的 ETP=0；
  4. 开启外部时钟模式 2，置 TIMx_SMCR 的 ECE=1；
  5. 启动计数器，置 TIMx_CR1 的 CEN=1。计数器在每 2 个 ETR 上升沿计数一次。

（4）内部触发输入

定时器之间可以通过内部触发线互连，一个定时器作为主、另一个作为从，由主定时器的触发输出驱动从定时器（详见 3.10）。

2.4 捕获 / 比较通道

每一个捕获 / 比较通道都围绕着一个捕获 / 比较寄存器（包含影子寄存器），包括捕获的输入部分（数字滤波、多路复用和预分频器）和输出部分（比较器和输出控制）。

  • 在捕获模式下，捕获发生在影子寄存器上，然后再复制到预装载寄存器中；
  • 在比较模式下，预装载寄存器的内容被复制到影子寄存器中，然后影子寄存器的内容和计数器进行比较；
  • 输出部分先产生一个中间波形 OCxREF（高有效）作为基准，链的末端决定最终输出信号的极性。

记忆点：普通定时器的「骨架」就是时基单元（CNT/PSC/ARR）+ 4 个捕获 / 比较通道。理解影子寄存器 / 预装载（尤其是 ARPE 位）是写对 PWM 和动态改参数的前提；3 种计数模式决定了波形形状；4 种时钟源让你既可用内部时钟做定时，也可用外部信号做计数。

三、普通定时器的工作模式

普通定时器支持非常丰富的工作模式，课件归纳为：输入捕获、PWM 输入、强置输出、输出比较、PWM、单脉冲、编码器接口、输入异或、定时器与外部触发同步（复位 / 门控 / 触发）、定时器同步，以及 PWM 下的边沿对齐与中央对齐。

3.1 输入捕获模式

在输入捕获模式下，当检测到 ICx 信号上相应的边沿后，计数器的当前值被锁存到捕获 / 比较寄存器（TIMx_CCRx）中。捕获事件发生时，相应的 CCxIF 标志（TIMx_SR）被置 1；若使能了中断或 DMA，则产生中断或 DMA 请求。若捕获发生时 CCxIF 已为高，则重复捕获标志 CCxOF 被置 1。写 CCxIF=0 或读取 TIMx_CCRx 可清除 CCxIF；写 CCxOF=0 可清除 CCxOF。

在 TI1 上升沿捕获计数器值到 TIMx_CCR1 的步骤：

  1. 选有效输入端：写 CC1S=01，使 TIMx_CCR1 连接到 TI1，通道被配置为输入，TIMx_CCR1 变为只读；
  2. 配输入滤波器：假设输入信号最多在 5 个内部时钟周期内抖动，则需滤波器带宽长于 5 个周期，可连续采样 8 次确认真实边沿，即在 TIMx_CCMR1 写 IC1F=0011；
  3. 选有效边沿：在 TIMx_CCER 写 CC1P=0（上升沿）；
  4. 配输入预分频器：希望每个有效电平转换都捕获，则禁止预分频，写 IC1PS=00；
  5. 允许捕获：设 TIMx_CCER 的 CC1E=1；
  6. 按需允许中断 / DMA：设 TIMx_DIER 的 CC1IE/CC1DE 位。

发生输入捕获时：计数器值被传送到 TIMx_CCR1；CC1IF 置位（若连续两次捕获且未清除则 CC1OF 也置 1）；若设了 CC1IE 则产生中断；若设了 CC1DE 则产生 DMA 请求。处理捕获溢出时，应先读数据再读溢出标志，避免丢失信息。

3.2 PWM 输入模式

PWM 输入模式是输入捕获模式的一个特例，区别是：两个 ICx 信号被映射至同一个 TIx 输入；这两个 ICx 信号边沿有效但极性相反；其中一个 TIxFP 信号被作为触发输入，从模式控制器被配置成复位模式。

若需测量输入到 TI1 上的 PWM 信号的长度（存于 TIMx_CCR1）和占空比（存于 TIMx_CCR2），步骤：

  1. 选 TIMx_CCR1 有效输入：CC1S=01（选 TI1）；
  2. 选 TI1FP1 有效极性（捕获到 TIMx_CCR1 并清除计数器）：CC1P=0（上升沿）；
  3. 选 TIMx_CCR2 有效输入：CC2S=10（选 TI1）；
  4. 选 TI1FP2 有效极性（捕获到 TIMx_CCR2）：CC2P=1（下降沿）；
  5. 选有效触发输入：TS=101（选 TI1FP1）；
  6. 配置从模式为复位模式：SMS=100；
  7. 使能捕获：CC1E=1 且 CC2E=1。

3.3 强置输出模式

在输出模式（CCxS=00）下，输出比较信号（OCxREF 和相应的 OCx）能够直接由软件强置为有效或无效状态，而不依赖比较结果。置 OCxM=101 可强置 OCxREF 为高（高有效），同时 OCx 得到与 CCxP 极性位相反的值；例如 CCxP=0（OCx 高有效）时，OCx 被强置为高。置 OCxM=100 可强置 OCxREF 为低。该模式下计数器与 CCRx 的比较仍在进行，相应标志仍会被修改，因此仍会产生中断和 DMA 请求。

3.4 输出比较模式

输出比较用来控制一个输出波形，或指示一段给定时间已到。当计数器与捕获 / 比较寄存器内容相同时，输出比较功能做如下操作：

  1. 将输出比较模式（OCxM 位）和输出极性（CCxP 位）定义的值输出到对应引脚：比较匹配时，输出可保持电平（OCxM=000）、被置有效（001）、被置无效（010）或翻转（011）；
  2. 设置 TIMx_SR 中的 CCxIF 标志位；
  3. 若设了 CCxIE 位，则产生中断；
  4. 若设了 CCxDE 位（及 TIMx_CR2 的 CCDS 位选择 DMA 请求功能），则产生 DMA 请求。

OCxPE 位选择 TIMx_CCRx 是否需要使用预装载寄存器。在输出比较模式下，更新事件 UEV 对 OCxREF 和 OCx 输出没有影响，同步精度可达一个计数周期；输出比较模式（在单脉冲模式下）也能输出一个单脉冲。

配置步骤：

  1. 选择计数器时钟（内部、外部、预分频器）；
  2. 将数据写入 TIMx_ARR 和 TIMx_CCRx；
  3. 若需中断 / DMA，设 CCxIE 和 / 或 CCxDE 位；
  4. 选输出模式，例如计数匹配时翻转 OCx、CCRx 预装载未用、高有效，则设 OCxM=011、OCxPE=0、CCxP=0、CCxE=1；
  5. 设 TIMx_CR1 的 CEN 位启动计数器。

3.5 PWM 模式

PWM（脉冲宽度调制）模式可以产生一个由 TIMx_ARR 确定频率、由 TIMx_CCRx 确定占空比的信号。在 TIMx_CCMRx 的 OCxM 位写入 110（PWM 模式 1）或 111（PWM 模式 2），即可独立设置每个 OCx 通道产生一路 PWM。

配置要点：

  • 设 OCxPE 位使能相应预装载寄存器，最后还要设 TIMx_CR1 的 ARPE 位，使能自动重装载的预装载寄存器；
  • 仅当发生更新事件时，预装载寄存器才能被传送到影子寄存器，因此计数器开始计数前，必须通过设 TIMx_EGR 的 UG 位来初始化所有寄存器；
  • OCx 极性由 TIMx_CCER 的 CCxP 位设置（高有效或低有效）；CCxE 位控制 OCx 输出使能。

（1）PWM 边沿对齐模式

  • 向上计数配置（DIR=0）：以 PWM 模式 1 为例，当 TIMx_CNT < TIMx_CCRx 时 OCxREF 为高，否则为低；若 CCRx 比较值大于 ARR，则 OCxREF 保持为 1；若比较值为 0，则保持为 0；
  • 向下计数配置（DIR=1）：以 PWM 模式 1 为例，当 TIMx_CNT > TIMx_CCRx 时 OCxREF 为低，否则为高；该模式下能产生 0% 占空比的 PWM 波形。

（2）PWM 中央对齐模式

当 TIMx_CR1 的 CMS 位不为 00 时即进入中央对齐模式。根据不同 CMS 位设置，比较标志可在向上计数、向下计数或双向计数时被置 1；DIR 位由硬件更新，不要软件修改。例如 CMS=01 时，在中央对齐模式下当计数器向下计数时设置比较标志。

使用中央对齐模式的注意事项（同 2.2 末尾）：不能软件同时改 DIR 和 CMS；不要在运行中改计数器；启动前用 UG 位做一次软件更新最保险。

3.6 单脉冲模式

单脉冲模式（OPM）是前述模式的特例，允许计数器响应一个激励，并在一个程序可控的延时之后，产生一个脉宽可程序控制的脉冲。可通过从模式控制器启动计数器，在输出比较或 PWM 模式下产生波形。设置 TIMx_CR1 的 OPM 位即选择单脉冲模式，让计数器在产生下一个更新事件 UEV 时自动停止。

仅当比较值与计数器初始值不同时才能产生脉冲。启动前需配置：向上计数方式要求 CNT < CCRx ≤ ARR（特别地 0 < CCRx）；向下计数方式要求 CNT > CCRx。

3.7 编码器接口模式

增量（正交）编码器可直接与定时器连接。选择编码器接口模式：

  • 只在 TI2 边沿计数：SMS=001；
  • 只在 TI1 边沿计数：SMS=010；
  • 同时在 TI1 和 TI2 边沿计数：SMS=011。

通过 CC1P 和 CC2P 可选择 TI1/TI2 极性，必要时对输入滤波器编程。两个输入 TI1 和 TI2 用作增量编码器的接口。计数器与编码器信号的关系由硬件按跳变顺序自动决定向上或向下计数，并相应设置 DIR 位。计数器只在 0~ARR 之间连续计数，因此计数前必须配置 TIMx_ARR；捕获器、比较器、预分频器、触发输出等仍正常工作。计数器内容始终指示编码器位置，计数方向与传感器旋转方向对应。

实际中一般会用比较器把编码器的差动输出转成数字信号以增强抗干扰；编码器的第三个信号表示机械零点，可接到外部中断输入并触发计数器复位。典型配置示例：CC1S=01、CC2S=01、CC1P=0、CC2P=0、SMS=011、CEN=1。

3.8 定时器输入异或功能

TIMx_CR2 的 TI1S 位允许通道 1 的输入滤波器连接到一个异或门的输出端，异或门 3 个输入端为 TIMx_CH1、TIMx_CH2 和 TIMx_CH3。异或输出可用于所有输入功能（如触发或输入捕获），此特性可用于连接霍尔传感器。

3.9 定时器和外部触发同步

定时器可在复位模式、门控模式或触发模式下与外部触发同步。

（1）复位模式

发生触发输入事件时，计数器和预分频器被重新初始化；若 URS=0 还会产生更新事件 UEV，所有预装载寄存器被更新。例如 TI1 上升沿导致向上计数器清零：配置通道 1 检测 TI1 上升沿（IC1F=0000、CC1S=01、CC1P=0）；置 SMS=100 为复位模式、TS=101 选 TI1 为输入源；置 CEN=1 启动。计数器正常计数直到 TI1 上升沿，此时被清零并从 0 重数，同时置 TIF 标志，可据 TIE/TDE 产生中断或 DMA。

（2）门控模式

按选中输入端电平使能计数器。例如计数器只在 TI1 为低时向上计数：配置通道 1 检测 TI1 低电平（IC1F=0000、CC1S=01、CC1P=1）；SMS=101 为门控模式、TS=101 选 TI1；置 CEN=1 启动（门控模式下若 CEN=0 则计数器不能启动）。只要 TI1 为低就计数，变高就停止，开始和停止时都置 TIF。

（3）触发模式

输入端选中的事件使能计数器。例如计数器在 TI2 上升沿开始向上计数：配置通道 2 检测 TI2 上升沿；SMS=110 为触发模式、TS=110 选 TI2。TI2 出现上升沿时计数器开始计数并置 TIF。

3.10 定时器同步

所有 TIMx 定时器在内部相连，用于定时器同步或链接。当一个定时器处于主模式时，它可以对另一个处于从模式的定时器的计数器进行复位、启动、停止或提供时钟等操作。典型应用包括：

  • 用一个定时器作为另一个定时器的预分频器；
  • 用一个定时器使能另一个定时器；
  • 用一个定时器启动另一个定时器；
  • 用一个外部触发同步地启动 2 个定时器。

示例：配置 TIM1 作为 TIM2 的预分频器。

  1. 配置 TIM1 为主模式，在每个更新事件 UEV 时输出周期触发信号：TIM1_CR2 的 MMS=010，每当产生更新事件在 TRGO1 上输出一个上升沿；
  2. 连接 TIM1 的 TRGO1 到 TIM2：设 TIM2_SMCR 的 TS=000，配置 TIM2 使用 ITR1 作为内部触发的从模式；
  3. 把 TIM2 从模式控制器置于外部时钟模式 1（TIM2_SMCR 的 SMS=111），TIM2 由 TIM1 周期性上升沿驱动；
  4. 分别设两个定时器的 CEN 位启动。

记忆点：3 这一节是定时器的「武功招式表」。输入捕获 / PWM 输入用来测信号，输出比较 / PWM / 强置用来发信号，单脉冲适合「延时 + 定宽」触发，编码器接口直接对接旋转编码器，异或功能服务霍尔传感器，外部触发同步（复位 / 门控 / 触发）和定时器同步让多个定时器联动。PWM 是其中最高频的应用，务必吃透边沿对齐与中央对齐、ARR 定频 CCRx 定占空、ARPE/OCxPE 与 UG 初始化的配合。

四、定时器相关寄存器

普通定时器 TIMx 的首地址是 0x40000000（以 TIM2 为例，基地址 0x40000000）。普通定时器的寄存器可以用半字（16 位）或字（32 位）方式操作。课件列出普通定时器共 18 个寄存器：

序号 寄存器 说明
1 TIMx_CR1 控制寄存器 1
2 TIMx_CR2 控制寄存器 2
3 TIMx_SMCR 从模式控制寄存器
4 TIMx_DIER DMA / 中断使能寄存器
5 TIMx_SR 状态寄存器
6 TIMx_EGR 事件产生寄存器
7 TIMx_CCMR1 捕获 / 比较模式寄存器 1
8 TIMx_CCMR2 捕获 / 比较模式寄存器 2
9 TIMx_CCER 捕获 / 比较使能寄存器
10 TIMx_CNT 计数器
11 TIMx_PSC 预分频器
12 TIMx_ARR 自动重装载寄存器
13 TIMx_CCR1 捕获 / 比较寄存器 1
14 TIMx_CCR2 捕获 / 比较寄存器 2
15 TIMx_CCR3 捕获 / 比较寄存器 3
16 TIMx_CCR4 捕获 / 比较寄存器 4
17 TIMx_DCR DMA 控制寄存器
18 TIMx_DMAR 连续模式的 DMA 地址

几个最常用寄存器的关键位（结合前文）：

  • TIMx_CR1（偏移 0x00）：CEN（位 0，计数器使能）、UDIS（位 1，禁止更新）、URS（位 2，更新请求选择）、ARPE（位 7，自动重装载预装载允许）、DIR（位 4，方向，中央对齐时由硬件改写）、CMS[1:0]（位 6:5，中央对齐模式选择）、OPM（位 3，单脉冲模式）；
  • TIMx_EGR（偏移 0x14）：UG（位 0，软件产生更新事件，用于初始化所有寄存器）；
  • TIMx_SMCR：SMS[2:0]（从模式选择，000 内部 / 111 外部时钟 1 / 100 复位 / 101 门控 / 110 触发 / 001~011 编码器）、TS[2:0]（触发选择）、ECE（外部时钟 2 使能）、ETF/ETPS/ETP（外部触发滤波 / 预分频 / 极性）；
  • TIMx_CCMR1/2：CCxS（捕获比较选择）、ICxF（输入滤波）、OCxM（输出比较模式，PWM 模式 1=110、模式 2=111）、OCxPE（输出比较预装载使能）；
  • TIMx_CCER：CCxP（极性）、CCxE（输出使能）。

五、定时器相关库函数

5.1 固件库函数所使用的数据结构

TIM 寄存器结构 TIM_TypeDef 在 stm32f10x.h 中定义。TIM 外设基地址声明如下（节选）：

c
#define PERIPH_BASE           ((u32)0x40000000)
#define APB1PERIPH_BASE       PERIPH_BASE
#define APB2PERIPH_BASE       (PERIPH_BASE + 0x10000)
#define TIM2_BASE             (APB1PERIPH_BASE + 0x0000)
#define TIM3_BASE             (APB1PERIPH_BASE + 0x0400)
#define TIM4_BASE             (APB1PERIPH_BASE + 0x0800)
...
#define TIM2                  ((TIM_TypeDef *) TIM2_BASE)
#define TIM3                  ((TIM_TypeDef *) TIM3_BASE)
#define TIM4                  ((TIM_TypeDef *) TIM4_BASE)

时间基数初始化所用的结构体：

c
typedef struct
{
    u16 TIM_Prescaler;           // 预分频值，0x0000~0xFFFF
    u16 TIM_CounterMode;         // 计数模式
    u16 TIM_Period;              // 自动重装载周期值，0x0000~0xFFFF
    u16 TIM_ClockDivision;       // 时钟分割
    u8  TIM_RepetitionCounter;   // 仅用于 TIM1 和 TIM8
} TIM_TimeBaseInitTypeDef;

各字段含义：

  • TIM_Prescaler：作为 TIMx 时钟频率除数的预分频值，取值 0x0000~0xFFFF；
  • TIM_CounterMode：计数模式，可取 TIM_CounterMode_Up（向上）、TIM_CounterMode_Down（向下）、TIM_CounterMode_CenterAligned1/2/3（中央对齐模式 1/2/3）；
  • TIM_Period：下一个更新事件装入自动重装载周期的值，取值 0x0000~0xFFFF；
  • TIM_ClockDivision：时钟分割，可取 TIM_CKD_DIV1（TDTS = Tck_tim）、TIM_CKD_DIV2（TDTS = 2×Tck_tim）、TIM_CKD_DIV4（TDTS = 4×Tck_tim）；
  • TIM_RepetitionCounter：仅用于 TIM1 和 TIM8。

5.2 常用的普通定时器固件库函数

（1）TIM_DeInit

c
void TIM_DeInit(TIM_TypeDef* TIMx);

将外设 TIMx 寄存器重设为缺省值。TIMx 可取 2~5。例：TIM_DeInit(TIM2)。

（2）TIM_TimeBaseInit

c
void TIM_TimeBaseInit(TIM_TypeDef* TIMx, TIM_TimeBaseInitTypeDef* TIM_TimeBaseInitStruct);

根据结构体指定的参数初始化 TIMx 时间基数单位。例：

c
TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
TIM_TimeBaseStructure.TIM_Period        = 0xFFFF;  // ① 自动重装载周期值
TIM_TimeBaseStructure.TIM_Prescaler     = 0xF;     // ② 时钟预分频数
TIM_TimeBaseStructure.TIM_ClockDivision = 0x0;     // ③ 时钟分割
TIM_TimeBaseStructure.TIM_CounterMode   = TIM_CounterMode_Up; // ④ 向上计数
TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);

（3）TIM_ITConfig

c
void TIM_ITConfig(TIM_TypeDef* TIMx, u16 TIM_IT, FunctionalState NewState);

使能或除能指定的 TIM 中断。TIM_IT 可取 TIM_IT_Update（更新中断）、TIM_IT_CC1~TIM_IT_CC4（捕获 / 比较中断）、TIM_IT_Trigger（触发中断）。例：TIM_ITConfig(TIM2, TIM_IT_CC1, ENABLE)。

（4）TIM_Cmd

c
void TIM_Cmd(TIM_TypeDef* TIMx, FunctionalState NewState);

使能或除能 TIMx 外设。例：TIM_Cmd(TIM2, ENABLE)。

（5）TIM_GetITStatus

c
ITStatus TIM_GetITStatus(TIM_TypeDef* TIMx, u16 TIM_IT);

检查指定的 TIM 中断是否发生，返回 SET 或 RESET。例：

c
if (TIM_GetITStatus(TIM2, TIM_IT_CC1) == SET)
{
    // 处理捕获比较 1 中断
}

（6）TIM_ClearITPendingBit

c
void TIM_ClearITPendingBit(TIM_TypeDef* TIMx, u16 TIM_IT);

清除 TIMx 的中断挂起位。例：TIM_ClearITPendingBit(TIM2, TIM_IT_CC1);

记忆点：库函数把「啃寄存器」封装成了结构体 + 几个函数。真正用定时做项目时，99% 的情况只需要 TIM_TimeBaseInit 配时基、TIM_ITConfig 开中断、TIM_Cmd 启动、TIM_GetITStatus/TIM_ClearITPendingBit 在中断里查询和清标志。掌握 TIM_TimeBaseInitTypeDef 的 5 个字段含义，就掌握了定时器的软件入口。

六、脉冲宽度调制及定时器实例分析

6.1 普通定时器 TIM2~TIM5 定时时间的计算

假设系统时钟 72 MHz，TIM1 由 PCLK2（72 MHz）得到，TIM2~TIM7 由 PCLK1 得到。定时时间的关键是设定时钟预分频数（TIM_Prescaler）和自动重装载寄存器周期值（TIM_Period）。

定时时间 T 的计算公式：

示例
T = (TIM_Period + 1) × (TIM_Prescaler + 1) / TIMxCLK

其中：

  • TIM_Period 是自动重装载寄存器周期的值；
  • TIM_Prescaler 是时钟预分频数；
  • TIMxCLK 是 TIMx 的时钟频率，一般为 72 MHz。

公式里 +1 的原因：计数器从 0 计到 Period 共 Period+1 个计数，预分频器把时钟除以 Prescaler+1。

示例（每 1 秒更新一次）：TIM2CLK 为 72 MHz，要使每 1 秒发生一次更新事件：

c
TIM_TimeBaseStructure.TIM_Period    = 9999;
// 自动重装载寄存器周期的值，累计 9999+1 个计数后产生更新或中断
TIM_TimeBaseStructure.TIM_Prescaler = 7199;
// 时钟预分频数，时钟频率 = 72×1000000 / (1+9999) / (1+7199) = 1 Hz
TIM_TimeBaseStructure.TIM_CounterMode   = TIM_CounterMode_Up; // 向上计数
TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;       // 定时器时可不设置

定时器应用的一般步骤：

  1. 系统初始化（主要初始化时钟等）；
  2. GPIO 初始化（用于 LED，便于观察）；
  3. TIMx 的配置；
  4. NVIC 的配置（中断优先级）；
  5. 编写中断服务函数。

6.2 使用固件库函数开发定时器应用的实例（例 8-1）

题目：利用定时器 2，每隔 0.5 秒，连接 PE0 的指示灯状态翻转一次。

解：在创建工程时选中 Device→Startup、CMSIS→CORE，以及 StdPeriph Drivers 中的 GPIO、Framework、RCC 和 TIM。定时时间按 6.1 公式反推：

  • TIMxCLK = 72 MHz，目标 T = 0.5 s；
  • 取 TIM_Prescaler = 7199，则 (Prescaler+1) = 7200；
  • (Period+1) = 0.5 × 72000000 / 7200 = 5000，故 TIM_Period = 4999。

完整参考代码：

c
#include "stm32f10x.h"

void TIMER2_Init(void);
void NVIC_Config(void);

void TIMER2_Init(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;

    // ① 定时 0.5s：T = (4999+1)×(7199+1) / 72MHz = 0.5 s
    TIM_TimeBaseStructure.TIM_Period        = 4999;
    TIM_TimeBaseStructure.TIM_Prescaler     = 7199;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode   = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);  // 打开更新中断
    TIM_Cmd(TIM2, ENABLE);                      // 启动定时器
}

void NVIC_Config(void)
{
    NVIC_InitTypeDef NVIC_InitStructure;
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1);
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

// 定时器 2 中断服务函数：每 0.5s 翻转 PE0 上的 LED
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        GPIO_WriteBit(GPIOE, GPIO_Pin_0,
                      (BitAction)(1 - GPIO_ReadOutputDataBit(GPIOE, GPIO_Pin_0)));
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}

说明：课件原文在例 8-1 处给出的是工程配置说明与函数框架，未提供中断服务函数完整代码；上面补全了符合 6.1 公式（Period=4999、Prescaler=7199 对应 0.5 s）和 5.2 库函数约定的标准实现，可直接用于教学演示。

记忆点：定时时间的核心就是那一条公式 T=(Period+1)×(Prescaler+1)/TIMxCLK。先定 TIMxCLK（通常 72 MHz），再在「分频够粗、周期够大」的前提下挑一组 (Period, Prescaler)，最后用 TIM_TimeBaseInit + TIM_ITConfig + TIM_Cmd 三连启动，在中断里查标志、清标志、翻转 IO。例 8-1 是这条流水线的标准范本。
