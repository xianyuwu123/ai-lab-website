概念速查：通道号、转换顺位、转换模式与中断标志
概念课堂上怎样区分
物理通道 CHx决定选择哪路模拟输入。同一个输入可以出现在不同顺位，也可以出现在规则组和注入组中。
顺位 Rank决定第几次转换。顺位1不等于通道1，可以配置成第1次转CH3、第2次转CH1。
规则组 / 注入组同一个ADC的两份转换安排，使用同一个转换核心，不是两个ADC同时工作。规则组最多16次，注入组最多4次。
SCAN是否沿配置序列转换多个顺位。并不意味着自动扫描所有物理输入，也不是多通道同时采样。
CONT本轮规则序列结束后是否自动开始下一轮。触发注入通常是单次扫描；注入跟着连续重复，使用JAUTO与CONT组合。
注入结束 JEOC整个注入序列完成后置位。STM32F1在注入组结束时也会置EOC，不能简单把EOC看作“只属于规则组”。
读数据与清状态读ADC_DR可清EOC。JEOC应由软件清除；不能照搬其他系列“读JDR自动清JEOC”的说法。STRT/JSTRT是开始标志，不是实时忙位。
状态标志与CPU中断标志置位不等于CPU立即进入中断，还要配置相应中断使能与NVIC。注入转换打断规则转换，是ADC内部调度，不需要CPU先进入中断。
从动画到配置：三个由易到难的程序片段

以下是 STM32F10x 标准外设库的配置片段，不是独立可运行工程。前提：已打开GPIO/ADC时钟，将输入引脚设为模拟模式，设置合法ADCCLK并完成ADC稳定、复位校准和校准。课件的典型时钟可用PCLK2=72 MHz、ADC分频6，得到12 MHz。

A. 一个通道，触发一次，取一个结果

adc.ADC_Mode = ADC_Mode_Independent;
adc.ADC_ScanConvMode = DISABLE;
adc.ADC_ContinuousConvMode = DISABLE;
adc.ADC_ExternalTrigConv = ADC_ExternalTrigConv_None;
adc.ADC_DataAlign = ADC_DataAlign_Right;
adc.ADC_NbrOfChannel = 1;
ADC_Init(ADC1, &adc);
ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 1,
                         ADC_SampleTime_13Cycles5);
// 完成使能、稳定和校准后：
ADC_SoftwareStartConvCmd(ADC1, ENABLE);
while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET) {}
uint16_t value = ADC_GetConversionValue(ADC1);

B. 三个规则通道，按3→1→5连续扫描

adc.ADC_ScanConvMode = ENABLE;
adc.ADC_ContinuousConvMode = ENABLE;
adc.ADC_NbrOfChannel = 3;
ADC_Init(ADC1, &adc);
ADC_RegularChannelConfig(ADC1, ADC_Channel_3, 1, ADC_SampleTime_13Cycles5);
ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 2, ADC_SampleTime_13Cycles5);
ADC_RegularChannelConfig(ADC1, ADC_Channel_5, 3, ADC_SampleTime_13Cycles5);
// 先配置并使能DMA1通道1：ADC1_DR → uint16_t samples[3]。
// 外设地址固定、内存地址递增、半字传输，连续采集使用循环模式。
ADC_DMACmd(ADC1, ENABLE);
// 完成使能、稳定和校准后，仅启动一次即可连续运行。
ADC_SoftwareStartConvCmd(ADC1, ENABLE);

C. 两个注入顺位，软件触发插入转换

// ADC已配置SCAN=ENABLE；这里只补充注入组设置。
ADC_AutoInjectedConvCmd(ADC1, DISABLE);   // JAUTO=0
ADC_InjectedSequencerLengthConfig(ADC1, 2);
ADC_InjectedChannelConfig(ADC1, ADC_Channel_7, 1, ADC_SampleTime_13Cycles5);
ADC_InjectedChannelConfig(ADC1, ADC_Channel_2, 2, ADC_SampleTime_13Cycles5);
ADC_ExternalTrigInjectedConvConfig(ADC1, ADC_ExternalTrigInjecConv_None);
ADC_ExternalTrigInjectedConvCmd(ADC1, ENABLE);
ADC_ClearFlag(ADC1, ADC_FLAG_JEOC);
ADC_SoftwareStartInjectedConvCmd(ADC1, ENABLE);
while (ADC_GetFlagStatus(ADC1, ADC_FLAG_JEOC) == RESET) {}
uint16_t j1 = ADC_GetInjectedConversionValue(ADC1, ADC_InjectedChannel_1);
uint16_t j2 = ADC_GetInjectedConversionValue(ADC1, ADC_InjectedChannel_2);
ADC_ClearFlag(ADC1, ADC_FLAG_JEOC);
// 是否清EOC要结合规则组采集/DMA/中断处理策略，不能盲目混用标志。

配置顺序寄存器时应停下转换。本页以独立ADC1为例，不展开双ADC同步、交叉采样和芯片勘误的全部条件。实际上板还要核对具体型号数据手册与勘误。
