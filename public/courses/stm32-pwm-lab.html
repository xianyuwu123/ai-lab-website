← / → 单步；空格播放／暂停
进阶实验：运行中把 CCR 从3改成7，为什么要开 OC1PE 预装载？

独立的小实验：ARR=9，向上计数，PWM1，高电平有效。当前 CNT=5，旧 CCR=3，输出已经变低。比较“立即生效”和“等下一次更新事件生效”。

上板案例：TIM2_CH1 / PA0 输出 1 kHz、25% 占空比 PWM

使用 STM32F10x 标准外设库。假定启动代码已配置系统时钟，实际 TIM2 输入时钟为72 MHz，PA0 使用默认映射并且没有被其他外设占用。GPIO 使用复用推挽输出。LED 按 PA0 → 限流电阻 → LED → GND 连接，高电平点亮。

#include "stm32f10x.h"

void PWM_PA0_Init(void)
{
    GPIO_InitTypeDef gpio;
    TIM_TimeBaseInitTypeDef base;
    TIM_OCInitTypeDef oc;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    GPIO_StructInit(&gpio);
    gpio.GPIO_Pin   = GPIO_Pin_0;
    gpio.GPIO_Mode  = GPIO_Mode_AF_PP;
    gpio.GPIO_Speed = GPIO_Speed_2MHz;
    GPIO_Init(GPIOA, &gpio);

    TIM_DeInit(TIM2);
    TIM_TimeBaseStructInit(&base);
    base.TIM_Prescaler     = 71;     // 72 MHz / 72 = 1 MHz
    base.TIM_Period        = 999;    // 1000拍一个周期：1 kHz
    base.TIM_CounterMode   = TIM_CounterMode_Up;
    base.TIM_ClockDivision = TIM_CKD_DIV1; // 不是PSC分频
    TIM_TimeBaseInit(TIM2, &base);

    TIM_OCStructInit(&oc);
    oc.TIM_OCMode      = TIM_OCMode_PWM1;
    oc.TIM_OutputState = TIM_OutputState_Enable;
    oc.TIM_Pulse       = 250;        // 高250拍 / 总1000拍 = 25%
    oc.TIM_OCPolarity  = TIM_OCPolarity_High;
    TIM_OC1Init(TIM2, &oc);

    TIM_OC1PreloadConfig(TIM2, TIM_OCPreload_Enable);
    TIM_ARRPreloadConfig(TIM2, ENABLE);
    TIM_GenerateEvent(TIM2, TIM_EventSource_Update); // UG，装入有效值
    TIM_ClearFlag(TIM2, TIM_FLAG_Update);
    TIM_Cmd(TIM2, ENABLE);
}

// 初始化后，定时器硬件自动输出，无需每个脉冲都进中断。
// 改成75%：下一个更新事件后生效。
// TIM_SetCompare1(TIM2, 750);

PSC=71、ARR=999 的工程例子比动画里的十格计数有更细的占空比调节步长，原理相同。0% 可设 CCR1=0；本例100%可设 CCR1=1000。若 ARR 已是16位最大值65535，不能再把65536写入16位 CCR，应另选参数或采用合适的强制输出方式。

TIM2 是通用定时器，不需要 TIM1/TIM8 的 MOE 主输出使能配置。这里也无需配置 NVIC 或编写中断函数。真实 LED 的限流电阻应按供电、正向压降、目标电流和引脚驱动能力选择；网页中的电压和亮度是教学近似。

课件对应、公式边界与官方依据

依据《第8章 定时器与脉宽调制16-9.pptx》：第65～68页的捕获／比较通道与输出链，第85～93页的PWM模式、预装载、极性和计数对齐，第141页的时基计算。本页讲PWM生成；第74～76页的PWM输入测量是另一用途。

课件第83、88页的波形需要同时说明模式与输出极性，才能判断高低关系。本页明确分开 OC1REF 和最终 PA0 电平。第91页“向下计数PWM1能产生0%”应修正：该模式的比较条件是 CNT≤CCR 时有效，CCR=0仍有CNT=0这一拍，不能直接产生0%的 OC1REF。

向上计数完整周期含 ARR+1 拍；中央对齐的0→ARR→0完整往返含2×ARR拍，端点不会重复停留。相同计数时钟下，每拍都只改变1，中央对齐不会数得更快。其两端可产生更新事件，但一次更新事件不等于一个完整PWM周期。

本页假定 TIM2、内部时钟、通道已使能，未启用外部清除、单脉冲、门控或DMA。0%／100%时输出为恒电平，仍可计算计数周期，但不再有周期性输出边沿。PWM1/PWM2改变参考波形，CC1P改变最终极性，两者要分开看。

fTIM应由实际RCC时钟树确定，不要直接把CPU主频代入。STM32F1常见配置中，APB预分频为1时定时器时钟等于对应PCLK，否则通常为2×PCLK，具体以芯片手册为准。

官方核对：ST RM0008 Rev 21，15.3.9 PWM mode（第387～390页），以及时基、计数器和寄存器章节。公式用于本页明确标注的配置，不代表任意计数模式都能套用同一表达式。
