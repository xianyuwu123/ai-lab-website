这里对应哪一种硬件情形？以 STM32F1 的 TIM2～TIM5 连续计数为例，参数保持不变、UDIS=0，不插入软件 UG 或外部复位。向上和中央对齐从 CNT=0 开始，向下从 CNT=ARR 开始。页面并排展示三个独立的计数例子；一只定时器一次选择一种模式。

依据：ST《RM0008》Rev 21，第 15.3.2 节（计数模式），第 375～376 页（中央对齐计数与更新事件）。中央对齐在 ARR−1→ARR 与 1→0 的边沿换向并产生 UEV；向上在 ARR→0、向下在 0→ARR 的边沿产生 UEV。打开官方手册（可选，需联网）。

UEV 是硬件更新事件；进入中断还需要更新中断使能、NVIC 等条件。TIM1/TIM8 若启用重复计数器，更新事件间隔还会改变。

一个计数周期，怎样变成一次更新事件？

本页初始参数：fTIM=1 MHz、PSC=9、ARR=4。从 CNT=0 开始逐个 CK_CNT 边沿走，观察 ARR 边界和 UIF。

先记住路线：计数时钟到来，CNT 走一步；计满 0 到 ARR 后，下一拍回到 0 并产生 UEV，UIF 置 1。

① 先算 CNT 的时钟

PSC 写入 N，分频系数是 N+1。

② 再数一轮有几拍

0 到 ARR 有 ARR+1 个计数状态，一轮需 ARR+1 个 CK_CNT 周期。

③ 中央对齐作对照

从 0 到 ARR 再回到 0，完整往返需要 2×ARR 个 CK_CNT 周期。

把波形翻译成寄存器：PSC、ARR、CNT、DIR、UIF
对象页面中的作用学生最容易混淆的地方
PSC配置分频系数 PSC+1，运行中配置值保持不变PSC=3 时，内部计数按 0→1→2→3→0 变化；回到 0 的这一拍给 CNT 一次计数有效边沿。
ARR规定计数边界向上模式有 0、1、…、ARR，共 ARR+1 个状态。
CNT保存当前计数值它只在 CK_CNT 有效边沿改变，不会跟每个 CK_INT 都变化。
CR1.DIR向上 / 向下方向；中央对齐时由硬件反映当前方向中央对齐模式会在 ARR 和 0 两端自动换向。
SR.UIF记录更新事件UIF 是标志位；是否进入 ISR 还要看 DIER.UIE、NVIC 与屏蔽状态。

教学动画把“更新事件”和“中断服务程序”分开。计数器产生 UEV 后，UIF 可以置位；CPU 是否响应则属于 NVIC 课程的内容。

两个容易算错的地方

APB 定时器时钟：在 STM32F1 中，如果相应 APB 预分频器等于 1，定时器时钟通常等于 PCLK；如果 APB 预分频器大于 1，定时器时钟通常为 2×PCLK。页面中的 fTIM 指已经送到定时器的时钟，不直接等同于总线频率。

中央对齐周期：一轮完整波形按 0 → ARR → 0 计算，需要 2×ARR 个 CK_CNT 周期。在本页 TIM2～TIM5 连续计数、UDIS=0、无额外 UG 或复位的条件下，两端各产生一次 UEV，更新事件的频率是完整往返频率的两倍。TIM1/TIM8 的重复计数器会进一步影响更新事件间隔。

对应的初始化代码框架 
// 例：fTIM = 1 MHz，PSC = 3，ARR = 5
// fCK_CNT = 1 MHz / (3 + 1) = 250 kHz
TIM2->PSC = 3;
TIM2->ARR = 5;
TIM2->CNT = 0;

// 向上：CMS = 00，DIR = 0
TIM2->CR1 &= ~(TIM_CR1_CMS | TIM_CR1_DIR);

// 向下：CMS = 00，DIR = 1
// TIM2->CR1 = (TIM2->CR1 & ~TIM_CR1_CMS) | TIM_CR1_DIR;

// 中央对齐：选择 CMS 非零的模式；CMS1/2/3 的差别主要涉及
// 输出比较标志在向上、向下或两个方向中的置位条件。
// TIM2->CR1 = (TIM2->CR1 & ~(TIM_CR1_CMS | TIM_CR1_DIR))
//             | TIM_CR1_CMS_0;

TIM2->EGR = TIM_EGR_UG;       // 装载 PSC 等预装载值，产生一次更新
TIM2->SR &= ~TIM_SR_UIF;      // 清掉初始化产生的 UIF
TIM2->DIER |= TIM_DIER_UIE;   // 如需更新中断
TIM2->CR1 |= TIM_CR1_CEN;     // 启动计数
