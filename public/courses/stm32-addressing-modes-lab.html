M[a]表示“读取地址a处的数据”，EA表示最后用于读取操作数的有效地址。下表访存次数仅统计取操作数的过程，不包含取指令。

寄存器寻址寄存器名R操作数 = R的内容0次
寄存器间接寻址保存地址的寄存器名REA = R；操作数 = M[EA]1次
间接寻址保存地址的内存单元地址AEA = M[A]；操作数 = M[EA]2次
相对寻址相对PC基准的偏移dEA = PC基准 + d取数示例为1次
变址寻址变址寄存器与偏移dEA = 变址寄存器内容 + d取数示例为1次

这里按教材的通用分类讲解。STM32的“先装入固定地址，再LDR”实现的是固定地址取数需求，最后的LDR仍是寄存器间接寻址，不把它另算直接寻址指令。相对地址也可用于跳转；本页统一演示取操作数。教材“变址”在本例对应ARM的基址寄存器加偏移形式。

三个小判断：你能分清地址与数据了吗？

假设R2 = 0x20000020，该地址处32位数据为42；地址0x20000008处保存指针0x20000020。

程序案例使用Cortex-M3汇编指令；原理框图的“R0 ← …”与M[ ]是说明记号，不是指令。数据取数案例使用SRAM地址，PC相对取数默认使用Flash地址；教材相对模型仍保留简化地址。上板前需要初始化题目中的寄存器与数据，并确保数据区由工程预留，不能直接覆盖现用SRAM；Flash常量应由链接布局放置，不是在运行中直接写入。参考：Arm Cortex-M3 Devices Generic User Guide，3.3.6与3.4节。网页可直接双击打开，无需联网。
