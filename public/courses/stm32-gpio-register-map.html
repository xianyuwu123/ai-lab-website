CNF / MODE 四位配置：16 种组合分别是什么输入输出模式？

    

    每个引脚在 CRL 或 CRH 中占 4 个配置位。从高位到低位依次是：
    

    CNF[1]CNF[0]MODE[1]MODE[0]
    

    先看低两位 MODE：00 是输入；01 / 10 / 11 是输出，分别选择 10 / 2 / 50 MHz 的速度等级。再按输入或输出，解释高两位 CNF。这里的 0、1 是寄存器中的配置位，不表示 PA 引脚此刻必然为低电平或高电平。
    

    全部 16 种组合：先选 MODE 所在列，再找 CNF 所在行
    

    单个引脚的四位字段 = (CNF << 2) | MODE；每格同时列出二进制、十六进制与模式。
    高两位
    CNF    		MODE = 00
    输入    		MODE = 01
    输出 · 10 MHz    		MODE = 10
    输出 · 2 MHz    		MODE = 11
    输出 · 50 MHz
    

    000000 · 0x0模拟输入关闭数字输入缓冲0001 · 0x1通用推挽输出10 MHz 速度等级0010 · 0x2通用推挽输出2 MHz 速度等级0011 · 0x3通用推挽输出50 MHz 速度等级
    

    010100 · 0x4浮空输入无内部上拉、下拉0101 · 0x5通用开漏输出10 MHz 速度等级0110 · 0x6通用开漏输出2 MHz 速度等级0111 · 0x7通用开漏输出50 MHz 速度等级
    

    101000 · 0x8上拉 / 下拉输入ODR=1 上拉；ODR=0 下拉1001 · 0x9复用推挽输出10 MHz 速度等级1010 · 0xA复用推挽输出2 MHz 速度等级1011 · 0xB复用推挽输出50 MHz 速度等级
    

    111100 · 0xC保留配置不应作为有效模式使用1101 · 0xD复用开漏输出10 MHz 速度等级1110 · 0xE复用开漏输出2 MHz 速度等级1111 · 0xF复用开漏输出50 MHz 速度等级
    

    

    读表示例：0110 = 01 | 10 = 0x6。先读 MODE=10，知道是 2 MHz 输出；再读 CNF=01，因此是通用开漏输出。但 0100 = 01 | 00 = 0x4 的 MODE 为 00，同样的 CNF=01 此时表示浮空输入。
    

    这些模式对引脚做了什么？
    

    

    输入：MODE = 00
      

    • CNF=00，模拟输入：数字输入缓冲关闭，常用于 ADC 等模拟信号通路；是否连接到相应外设还取决于芯片引脚与外设配置。
      • 

    • CNF=01，浮空输入：数字输入开启，无内部上下拉，电平由外部电路决定；悬空时不能保证读到 0 或 1。
      • 

    • CNF=10，上拉 / 下拉输入：用对应的 ODR 位进一步选择：1 接内部上拉，0 接内部下拉。IDR 读到的是实际引脚电平。
      • 

    • CNF=11，保留：1100 / 0xC 不对应有效的输入工作模式。
      • 

    

    输出：MODE = 01、10 或 11
      

    • CNF=00，通用推挽：ODR=1 主动拉高，ODR=0 主动拉低，适合本页高电平有效的 LED 示例。
      • 

    • CNF=01，通用开漏：ODR=0 拉低；ODR=1 释放引脚，呈高阻态。要获得稳定高电平，通常需要外部上拉。
      • 

    • CNF=10，复用推挽：由定时器、串口等外设信号控制推挽输出级；具体功能由引脚映射和外设设置决定。
      • 

    • CNF=11，复用开漏：由外设控制拉低或释放引脚，例如符合对应引脚功能的 I²C 信号。
      • 

    

    

    上拉和下拉为什么都是 1000？
    

    CNF=10、MODE=00 → 1000 → 0x8 只选择“上拉 / 下拉输入”这一类；对应 ODR 位决定具体方向。以下以 PA0 为例，假设 GPIOA 时钟已使能：
    

    // PA0 上拉输入：先预置 ODR[0]=1，再把 PA0 配置为 1000
GPIOA->BSRR = 1u;
GPIOA->CRL = (GPIOA->CRL & ~0xFu) | 0x8u;

// PA0 下拉输入：ODR[0]=0，四位配置仍为 1000
GPIOA->BRR = 1u;

// 外部电路可以把电平拉到相反方向；应从 IDR 读取实际电平
uint32_t input = GPIOA->IDR & 1u;
    

    从四位配置读懂整字数值
    

    CRL = 0x44444442 中，最右边的 2 = 0010 对应 PA0，表示通用推挽输出、2 MHz；其余七个 4 = 0100 分别对应 PA1—PA7，表示浮空输入。每个十六进制数字恰好对应一个引脚的四位配置。
    

    PA0—PA7 看 CRL；PA8—PA15 看 CRH。例如 PA0 使用 CRL[3:0]，PA1 使用 CRL[7:4]，PA8 使用 CRH[3:0]。修改某个引脚时，先用掩码清除它的四位，再写入目标配置，保留其他引脚的配置。
    

    速度等级不会自动产生波形：MODE=10 选择 2 MHz 速度等级，不会让 LED 自动以 2 MHz 闪烁。闪烁节奏由软件写入的时刻或定时器等外设决定。复用输出还需要配置相应外设；仅修改这四位不能启动串口、PWM 或 I²C。
    

    适用于本页 STM32F1 的 CRL / CRH 编码。配置和上下拉选择可对照 ST 官方 GPIO 初始化实现；MODE 速度编码可对照 官方 GPIO 头文件。
