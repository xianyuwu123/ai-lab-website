课堂易错点：先把这几组概念分开
容易混淆正确理解
字符/秒、bit/s、Baud8N1 每字符占10个线路位时间。120字符/秒，对应1200 bit/s、1200 Baud（连续发送，无额外空闲）。
TXE 与 TCTXE=1：发送数据缓冲空了，可以写下一个字节。TC=1：最后一帧也已发送完毕，且缓冲为空。
起始位与 RXNE检测到起始位只是开始收。数据进入接收数据寄存器后，RXNE 才置1；不是一看到下降沿就置1。
接收溢出 ORE本页采用 STM32F1：旧的未读 RDR 数据保留，新到数据丢失。不同芯片不能一概而论。
读 DR 与写 DR同一个软件地址，读的是 RDR，写的是 TDR。两条硬件通路彼此独立，不是写什么就读回什么。
USARTDIV 与 BRRUSARTDIV 是分频数，不是另一个寄存器。BRR 低4位表示十六分之一，不是十进制小数。
异步、串行、全双工这是三个不同维度：是否共享时钟、数据如何排队传、通信方向如何安排。UART 可以同时是异步、串行、全双工。
上板时怎样用：USART1 / 115200 / 8N1 的轮询收发代码

面向 STM32F103、CMSIS 寄存器定义。前提：系统已配置 PCLK2=72 MHz，USART1 默认引脚 PA9/PA10，没有重映射；对端为兼容的3.3 V逻辑电平串口并共地，不能直接接 RS-232 电平。这里只展示初始化和单字节收发，未包含系统时钟配置。

#include "stm32f10x.h"

void USART1_Init_Demo(void) {
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_USART1EN;
    (void)RCC->APB2ENR;
    // PA9：复用推挽输出 2 MHz；PA10：浮空输入
    GPIOA->CRH = (GPIOA->CRH & ~((0xFU << 4) | (0xFU << 8)))
                 | (0xAU << 4) | (0x4U << 8);
    USART1->CR1 = 0;        // 先停用后配置
    USART1->CR2 = 0;        // 1停止位，异步模式
    USART1->CR3 = 0;        // 不用流控、DMA
    USART1->BRR = 0x0271;   // 72 MHz / 115200 = 625 = 0x0271
    USART1->CR1 = USART_CR1_UE | USART_CR1_TE | USART_CR1_RE;
                            // M=0、PCE=0：8位数据、无校验
}

void USART1_SendByte(uint8_t data) {
    while ((USART1->SR & USART_SR_TXE) == 0) {}
    USART1->DR = data;       // 前面已读SR；本次写DR清TXE及TC
}
void USART1_WaitEnd(void) {
    while ((USART1->SR & USART_SR_TC) == 0) {}
}

// 返回：0 暂无数据；1 收到正常数据；-1 有错误（示例直接丢弃）
int USART1_TryReceive(uint8_t *out, uint32_t *error) {
    uint32_t sr = USART1->SR;            // 先保存状态
    uint32_t err = sr & (USART_SR_PE | USART_SR_FE
                           | USART_SR_NE | USART_SR_ORE);
    *error = err;
    // F1要求：PE存在时，等RXNE置1后再完成清除序列
    if ((err & USART_SR_PE) && !(sr & USART_SR_RXNE)) return 0;
    if ((sr & USART_SR_RXNE) || err) {
        uint32_t dr = USART1->DR;        // 再读DR，完成错误清除序列
        if (err) return -1;             // 清标志不等于修复或找回数据
        *out = (uint8_t)(dr & 0xFFU);   // 本例8N1
        return 1;
    }
    return 0;
}

连续高速收发应及时处理接收数据，可进一步使用中断、DMA 和软件缓冲。标志位置1不等于一定进入中断，还要满足相应中断使能条件。本页不模拟中断嵌套。
